# Failure catalogue

No team-observed failures have been added to this catalogue.

Add an entry only when a team experiment records the failure. Use
[the template](../templates/failure.md), link the experiment and its evidence,
and give the observed rate (n failures in m attempts).

Upstream issue summaries belong in the
[research notes](../research/fairydust-status.md#upstream-issues). They are
background research and do not establish a failure in the team's setup.

**Status values:** `reproduced` → `diagnosed` → `fix-in-progress` → `fixed`,
or `wont-fix` / `out-of-scope`.

Keep one file per failure class, `F-NNN-slug.md`, numbered from `F-001`, and
list it below when added.
