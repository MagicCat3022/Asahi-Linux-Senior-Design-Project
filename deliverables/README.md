# Deliverables

Sources for the course reports. Each report cites experiments
(`docs/experiments/...`) and failure entries (`F-NNN`), so every claim can be
traced to evidence.

| Folder | Deliverable | Built from |
| --- | --- | --- |
| [proposal/](proposal/) | Project proposal and plan (October 2026) | LaTeX source still to be added |
| `failure-catalogue/` | Failure catalogue report | [docs/failures/](../docs/failures/) |
| `diagnosis-report/` | Diagnosis report | Failure entries with status `diagnosed` or later, plus their experiments |
| `final-report/` | Final report (at least 15 pages) and demo notes | Everything above |

Create each folder when work on it starts.

## Submitting

1. Build the PDF from the source in its folder.
2. Tag the commit: `git tag deliverable/proposal-v1`.
3. Upload the PDF to SharePoint `02 Submitted deliverables/` as
   `YYYY-MM-DD-name.pdf`.

The PDF on SharePoint is the submitted copy. Edit only the source here.
